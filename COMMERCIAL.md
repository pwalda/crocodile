## When you need one

The AGPL lets anyone use, change and share Crocodile, including commercially,
as long as they pass the same freedoms on. You need a commercial licence if
you want to do any of these **without** publishing your source under the
AGPL:

- ship a product, app or device that includes Crocodile's AGPL code (for
  example the client core or call host) as closed source;
- offer a modified Crocodile client or server as a hosted service without
  giving its users the modified source;
- distribute Crocodile code under terms that conflict with the AGPL (for
  example some app store terms).

## When you don't

- Using the official apps, for any purpose, including at work.
- Running unmodified coordination servers or directories, including for
  your organisation or the public.
- Building your own client or bot on `packages/protocol` and
  `packages/crypto` alone (Apache-2.0).
- Changing Crocodile and publishing your changes under the AGPL.

A commercial licence covers the code only. Using the name "Crocodile" or the
logo is a separate permission; see [TRADEMARKS.md](TRADEMARKS.md).
