# Trademark policy

"Crocodile" (as the name of this communicator) and the crocodile logo are
trademarks of the Crocodile maintainer (GitHub user
[@pwalda](https://github.com/pwalda), the "Maintainer" in [CLA.md](CLA.md)).
The software licenses (AGPL-3.0 and Apache-2.0) cover the code; they do
**not** grant rights to the name or logo.
This protects users from confusing look-alikes, for example a modified build
that someone else distributes under our name.

## You may, without asking

- Say that your software works with Crocodile, or is based on Crocodile
  ("a fork of Crocodile", "compatible with Crocodile").
- Distribute **unmodified** official releases under the Crocodile name.
- Run a coordination server or directory with the unmodified software and say
  it is a "Crocodile coordination server".
- Use the name and logo in articles, reviews, talks and tutorials about the
  project.

## Please ask first

- Distributing a **modified** app or server under the Crocodile name or logo.
  Forks are welcome, but need their own name and logo.
- Using the name or logo in a product name, company name, domain name or app
  store listing.
- Merchandise.

## Always

- Don't suggest the project endorses you unless it does.
- Don't alter the logo or combine it with other marks.

Questions: open an issue or contact the maintainer.
